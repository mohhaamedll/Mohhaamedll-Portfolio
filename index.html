001

Secure File Locker

FLS
GitHub →

A command-line hybrid encryption tool — AES-256 in CTR mode handles fast file encryption, while RSA-2048 (OAEP) protects the AES key and nonce before storage in a MySQL database. Each file gets its own unique RSA key pair, splitting decryption authority between local storage and the database so neither side alone is sufficient.

Hybrid encryption — symmetric speed + asymmetric key protection
Per-file RSA-2048 key pair generation
Chunked in-place I/O — memory efficient on large files
Robust input validation via reusable ErrorHandler class
PythonAES-256-CTR RSA-2048 OAEPMySQLPyCryptodome

Point of Sale System

POS
GitHub →

A terminal-based POS system with full inventory and transaction management. Employee authentication gates all privileged operations, a cart system validates stock in real time, and every confirmed sale is logged to the database. Clean OOP architecture with layered inheritance keeps business logic separated from data access.

Employee login gate for all inventory operations
